Privacy policy

This application is a personal tool used by one person, its owner. It uses Google Drive only to store encrypted backup files that it creates in the owner's own Google Drive.

It requests the drive.file permission, which only allows access to files the application itself created. It cannot see any other file in the Drive.

The application does not collect, share, sell or transfer any user data to anyone. Backup files are encrypted before upload and are used only by the owner. Access can be revoked at any time in the Google account's security settings.
